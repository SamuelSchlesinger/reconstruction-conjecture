Interpretation:

- "isomorphism classes" matches A000088 exactly for n = 3, 4, 5, 6:
  4, 11, 34, 156. This sanity-checks the enumeration and the canonical
  labelling.
- "distinct decks" equals the number of isomorphism classes, so the
  deck is *injective* on isomorphism classes for these n. That is the
  reconstruction conjecture at order n.

For n = 2 the map is not injective (both graphs on 2 vertices have the
deck { K_1, K_1 }), which is why the conjecture is stated for n >= 3;
for n = 1 there is only one graph.

For n = 7 (not run above due to the naive O(n!) canonical-labelling
implementation) one should expect 1044 isomorphism classes and 1044
distinct decks; a nauty-backed version of this script would do this in
well under a second.
