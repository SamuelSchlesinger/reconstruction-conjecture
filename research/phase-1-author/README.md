# Phase 1 — Author Snapshot

This directory is a **frozen copy** of the corpus as produced by the Phase 1
parallel authoring agents, before Phase 2 (multi-lens review) and Phase 3
(revision). It is preserved so the pre-review state can be compared against
the revised state after the review cycle.

The live (working) copy that Phase 2 and Phase 3 operate on lives in the
parent directory. Do **not** edit files under `phase-1-author/`.

Corresponding git commit: `author: initial corpus for Reconstruction Conjecture`.
